# UPDATED PORTFOLIO

**Files:**
- index.html: Main portfolio page.
- style.css: Styles for the main page and project details.
- script.js: Main page menu and animations.
- projeto.html: Reusable project details page for all projects.
- projeto.js: Project content displayed on projeto.html.

**How to open:**
1. Extract all files into the same folder.
2. Open index.html in your browser.
3. In the Projects section, click "About the Project" to open the details page.
